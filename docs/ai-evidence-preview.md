# AI evidence preview foundation

`AiEvidencePreview` is an internal owner-only read operation. It resolves explicitly selected statement snapshot IDs within one workspace/stock asset, recalculates the existing exact metrics and optionally reads the expected current journal revision. A workspace transaction lock and repeated owner check keep the thesis selection coherent with journal writes. Foreign snapshots/assets/trades, incompatible snapshot mappings, damaged saved evidence and stale journal revisions block the preview.

The `ai-evidence-1` projection contains only asset symbol/exchange/quote currency, metric formula version, immutable snapshot IDs/fingerprints/UTC retrieval dates, bounded reporting context and eight computed metrics with exact decimal strings and coverage reasons. It selects the latest two distinct annual fiscal dates and four distinct quarterly fiscal dates. All currency groups at those dates remain visible; more than twelve selected groups fail instead of hiding ambiguity. `omitted_reports` explicitly counts excluded older report groups. Unknown inputs and capex conventions remain null/explicit; they never become zero.

Only an explicitly selected thesis is included. The application strips supported rich HTML into plain text, retaining the selected trade ID/current revision. Images, account balances, fills, strategies, emotions, lessons, unrelated notes, workspace/actor IDs, raw provider payloads and credentials are not projected. Input prose and asset labels remain untrusted data; a future transport must never interpret them as instructions. A thesis can be empty but cannot exceed 8,000 UTF-8 bytes or contain disallowed control characters. No silent truncation.

Canonical field order, sorted source keys and deterministic fiscal/currency ordering produce a SHA-256 fingerprint over the exact JSON bundle. Changed selected facts, source provenance or thesis revision change the fingerprint. Total JSON is limited to 65,536 bytes. This byte limit is not a token count or a spending reservation bound.

This milestone is **preview only**. It records no approval or consent, reserves no budget, persists no bundle/review and exposes no new REST/UI action. It performs no provider or AI request. Owner review/approval bound to the fingerprint, immutable evidence/review persistence, dispatch-time catalog enforcement, comparisons/raw financial facts and response/citation validation remain later work. Saved evidence may be old; retrieval dates stay explicit. Reporting-duration/accounting-policy compatibility is unverified, comparisons/news/prices are excluded and the bundle makes no investment recommendation.

No schema migration or release ZIP. Synthetic unit/integration fixtures cover canonicalization, exact values/unknown coverage, bounded history/currency ambiguity, scope/permissions, stale and damaged journals, exclusions and unchanged financial/spending/audit history after preview reads.

Schema-14 development now adds a separate immutable approval operation; the preview-only/no-schema paragraphs above describe the original preview milestone. See [approval contract](ai-evidence-approvals.md). Preview reads remain free of approval, spending and external-processing effects.
