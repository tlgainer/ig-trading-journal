# Save a stored AI response as a private review

Settings > AI summary settings > Saved AI request activity now offers **Save as review** for eligible completed responses. This stores a private workspace review from its immutable saved receipt. It makes no OpenAI or market-data request, counts no tokens, retries no delivery and changes neither captured usage charges nor posted financial history. It is separate from generating new output.

Eligibility is recomputed from server records: settled request, exact approved evidence, complete usable receipt, valid summary/source structure and original authorizing owner. Refused, invalid, missing, pending, uncertain, overrun or incompatible output does not grant an action. Another owner may read authorized history but cannot publish a request authorized by someone else. Existing saved reviews display their review ID instead of another save button. Readiness and processing switches do not enable generation through this action.

The owner-only POST `/workspaces/{id}/ai-requests/{request_id}/publish` accepts an empty JSON object. Client summary text, model, usage, pricing, approval replacements and receipt bodies are rejected. Existing HTTPS, session/nonce, explicit membership and private response protections apply. The server loads the existing receipt and calls the guarded review operation. Its deterministic immutable command identity reuses the same review on an exact retry; append and audit occur atomically. Failed audit rolls back publication without changing known usage charges. Results contain existing review metadata, not provider bodies or credentials.

Activity metadata now includes only `can_publish` and nullable `review_id` in addition to its previous fixed fields. Eligibility is advisory; every write checks its source again. Invalid evidence fails closed. Clicking save preserves unsaved budget/model/consent fields and holds the shared write guard through the activity refresh. An uncertain save outcome disables that row until an explicit reload. Reload shows the saved ID if the write succeeded, otherwise a still-eligible action. Retrying publication never regenerates output.

After saving, open Research > Stock fundamentals for the stock and reload **Saved AI reviews** to read the summary and original approved evidence. It remains AI-generated interpretation; citation membership does not prove a claim is true. Saving makes no public post or external share.
